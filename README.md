Projeto Unity — Espadas da Mesa de Pedra
Descrição do Projeto

Este projeto foi desenvolvido na Unity versão 6000.3.15f1 e apresenta um cenário medieval/fantasia onde o jogador pode interagir com uma mesa de pedra e retirar três espadas diferentes. O ambiente foi construído utilizando elementos naturais e arquitetônicos para criar uma atmosfera imersiva.

O objetivo principal da cena é permitir a interação do jogador com as espadas posicionadas sobre a mesa de pedra, proporcionando uma experiência visual simples e interativa.

Funcionalidades
Interação com 3 espadas posicionadas na mesa de pedra
Cada espada possui uma cor diferente:
🟡 Amarela
🔵 Azul
🔴 Vermelha
Cenário composto por:
Paredes de pedra texturizadas
Árvores com assets externos
Chão com textura de grama
Skybox para ambientação do cenário
Colunas gregas decorativas
Cilindros giratórios no topo das colunas
Tecnologias Utilizadas
Unity Engine
C#
Assets e texturas externas
