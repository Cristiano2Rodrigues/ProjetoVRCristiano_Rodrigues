🗡️ Projeto Unity — Espadas da Mesa de Pedra
📖 Descrição do Projeto
Este projeto foi desenvolvido na Unity versão 6000.3.15f1 e apresenta um cenário medieval/fantasia onde o jogador pode interagir com uma mesa de pedra e retirar três espadas diferentes.
O ambiente foi construído utilizando elementos naturais, texturas externas e objetos decorativos para criar uma atmosfera imersiva e visualmente agradável.
O principal objetivo da cena é proporcionar uma experiência simples de interação em um ambiente 3D estilizado, explorando conceitos de ambientação, organização de cenário e manipulação de objetos dentro da Unity.

⚔️ Funcionalidades
Interação com 3 espadas posicionadas na mesa de pedra
Cada espada possui uma cor diferente:
🟡 Espada Amarela
🔵 Espada Azul
🔴 Espada Vermelha
Ambiente medieval/fantasia contendo:
🪨 Paredes de pedra texturizadas
🌳 Árvores utilizando assets externos
🌱 Chão com textura de grama
☁️ Skybox para ambientação do cenário
🏛️ Colunas gregas decorativas
🔄 Cilindros giratórios no topo das colunas
🎵 Som ambiente adicionado para aumentar a imersão do jogador
⚙️ Script em C# utilizado para controlar a rotação dos cilindros decorativos

🛠️ Tecnologias Utilizadas
Unity Engine
C#
Assets e texturas externas
Sistema de áudio ambiente
Scripts de rotação para objetos decorativos
